1.7.1 修复了什么

1 · /kill 与 /c4clear 清不掉 C4 FIXED

旧版 C4 不可伤害、不可摧毁，/kill 对它没用；/c4clear 又只看已加载实体， 藏在未加载区块里的 C4 清不到，玩家走近后还会复活继续倒计时。

现在：C4 会把自己的坐标记进维度存档；清场时对“坐标在、实体不在场上”的 C4 只写一条 “死亡名单”，不加载区块、不每 tick 轮询；该 C4 被加载出来的瞬间查表命中、当场自删， 一 tick 都不跑。清场开销与地图大小无关。

2 · 提示 UI 改回复用模组原有的独立 UI CHANGED

删除 1.7.0 另写的 HUD，改回模组自带的 ClientMessageRenderer： 所有提示与进度都在准心下方一行，不挡准心、不挡视野。

1.7.0 修复了什么

1 · 滴滴声：警匪双方任何位置都能听见 FIXED

旧版用一次性 playSound（只有约 48 格内的玩家收得到），实体卸载时还会执行 stopsound @a 把所有人的倒计时音效掐断；C4 所在区块没玩家时引信还会停摆。

现在：声音由服务端逐个玩家广播（坐标取玩家自身位置，不会被距离衰减成 0）， 节奏由服务端引信驱动、随时进服都能对上，安装后给区块加 FORCED 票据，无人值守也照常滴滴。

2 · 安装后全员小字提示 NEW

下包瞬间，所有玩家屏幕上方显示小字“C4 已被安装”，拆除/爆炸同样有全员提示。

3 · 拆除进度全员可见 FIXED

拆除进度改为实体同步字段，所有人都会看到“XXX 正在拆除 C4” + 进度条 + 百分比，不再只有拆除者自己能看见。

4 · 拆除时允许被小幅度推动 IMPROVED

不再用方块坐标判断“是否移动”，而是按 1 格水平容差 判定：被队友/实体碰撞推一下不会中断， 真正走开才会中断。计时也从系统时钟改为服务端 tick。

玩法

操作说明
安装手持 C4 站在允许的方块上（默认 minecraft:end_stone_bricks），按住右键 3.5 秒
拆除对准 C4，剪刀 5 秒 / 空手 10 秒，右键开始
引信40 秒后爆炸，最后 20 / 10 / 4 秒有文字提醒

记分板联动

#C4 的 c4_condition : 0 空闲 / 1 已安装 / 2 已爆炸 / 3 已拆除
#C4 的 p1score/p2score/p3score : C4 坐标 X/Y/Z
/c4clear : 清除场上所有 C4（权限 2）

校验与自检

发布包在真实 Forge 专用服务器上跑过完整自检：安装 → 记分板 → 区块票据 → 滴滴声节奏 → 爆炸 → 剪刀拆除 → 推动容差 → 双人抢拆 → NBT → 真实 tick 推进。

专用服务器自检（66 项全部 PASS）：
java -Dqis4c4.selftest=true -Xmx2G @user_jvm_args.txt \
     @libraries/net/minecraftforge/forge/1.20.1-47.4.16/unix_args.txt nogui

开发环境：./gradlew runServer -Dqis4c4.selftest=true
