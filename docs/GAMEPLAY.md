# C4 Pro 玩法与逻辑说明书（1.7.4）

> 这份文档按**代码实际行为**逐条写，供核对。所有数值都能在源码里对应到常量：
> `C4Constants.java`、`C4Item.java`、`C4Entity.java`、`C4DropHandler.java`、`C4ClearCommand.java`、`Config.java`。
> 最后一节列出“与原始模组（qisumei 原版 1.1.0）的差异”，方便你确认核心玩法没被动过。

---

## 1. 物品

| 项 | 值 |
|----|----|
| 物品 ID | `qis4c4:c4`（创造模式物品栏 “C4 Pro”） |
| 堆叠上限 | 1 |
| 使用动画 | `UseAnim.BLOCK`（长按） |
| 长按时长 | **70 tick = 3.5 秒** |

## 2. 安装（下包）

### 2.1 允许安装的前置条件（任一不满足 → 右键直接失败，物品不消耗）

1. **队伍**：`allowed_install_teams`（匪）为空 → 允许所有人；非空 → 只有名单内的队伍可以；
   名单里显式写了 `""` → 只允许“没有队伍”的玩家。
2. **脚下方块**：玩家 `blockPosition().below()` 的方块 ID 必须在 `allowed_blocks` 里（默认 `minecraft:end_stone_bricks`）。
3. **放置点**：优先玩家脚下那一格（可替换方块）；被占用则抬高一层；都不可替换 → 失败。
4. **附近不能已有 C4**：玩家包围盒外扩 1.0 格内有 C4 实体 → 失败。

失败时只给**该玩家**一条屏幕小字（3 秒）：

- `§c 您的队伍不允许安装C4！允许的队伍: §e…`
- `§c C4只能放置在指定方块上！允许: §e…`
- `§c 无法在此位置安装C4！`
- `§c 附近已经有C4了！`

### 2.2 长按过程

- 每 tick 把玩家**水平速度清零**并取消疾跑（防止边走边装），竖直方向不限制。
- 屏幕上出现安装进度环（`INSTALL_START` 包，3500 ms）。
- 提前松手：
  - 已按 < 10 tick → `§c 安装已取消！`（2 秒）
  - 已按 ≥ 10 tick 但没到 70 → `§c 安装中断！请长按完成安装`（2 秒）
  - 两种情况都会发 `INSTALL_END` 把进度环清掉。

### 2.3 安装成功（第 70 tick）

1. 在放置点播放原版 `block.note_block.hat`（0.8 音量 / 0.9 音调）；
2. 清掉该点可能残留的“清理死亡名单”记录（`/c4clear` 留下的墓碑），避免刚装好就被判死刑；
3. 生成 C4 实体（碰撞箱 0.7 × 0.3，位置 = 方块中心 +0.05 高度）；
4. 给**该玩家**：`§a C4已安装在脚下！40秒后引爆`（3 秒）；
5. 非创造模式消耗 1 个物品；
6. 实体第一个 tick 时对**同维度所有玩家**：
   - HUD 小字 `§eC4 已被安装`（4 秒）；
   - 音效 `qis4c4:c4plant`（Bomb has been planted 语音，1.0/1.0）；
   - 音效 `qis4c4:c4countdown`（40 秒整段倒计时，**3.0**/1.0）；
   - 记分板 `c4_condition` → **1**，`p1score/p2score/p3score` → 安装点 X/Y/Z。

## 3. C4 实体

### 3.1 引信

| 项 | 值 |
|----|----|
| 总时长 | **800 tick = 40 秒** |
| 推进方式 | 服务端权威；每 tick 减 1，到 0 立即爆炸 |
| 区块 | 给所在区块加 **FORCED 票据（半径 2）**，装完就加载；移除/爆炸/拆除时释放 |
| 兜底 | `C4Manager` 每 tick 结束时检查“本 tick 没被区块推进过”的 C4，补一次逻辑（实测：区块加载但不在 entity-ticking 时引信仍准确） |
| 阶段提示 | 剩 20 秒 `§eC4 还剩 20 秒！`、剩 10 秒 `§6C4 还剩 10 秒！`、剩 4 秒 `§cC4 即将爆炸！`（同维度聊天栏，各一次） |

### 3.2 滴答声

- 音效：原版 `minecraft:block.note_block.hat`，音量 1.5，音调 1.0；
- 节奏：`interval = max(8, (int)(40 × (1 − progress × 0.8)))`，`progress = 1 − 剩余/800`
  → 满引信 40 tick（2 秒）一次，归零前收紧到 8 tick（0.4 秒）一次；
- 第一次滴答出现在**剩余 40 tick**（最后 2 秒），前面靠 `c4countdown` 整段音轨自带节奏；
- 投递：**同维度每位玩家各发一个声音包**（坐标取玩家自身位置），所以远处、另一阵营都听得见。

### 3.3 倒计时音轨（40 秒整段）怎么做到“中途接上”

音轨只有一整段，Minecraft 的声音包不能从中间播，所以：

- 用 `tools/gen_countdown_segments.py` 在**静音点**把它切成 39 段（`qis4c4:cd_NN`），切点无声；
- C4 每 0.5 秒检查一次“谁在听觉半径内”，**新进入的玩家只收到一个同步包**
  （已经过去多少毫秒 + 按距离算好的音量）；
- 客户端从对应那一段开始，按每段真实时长排队一段接一段播下去；
- 下包 20 秒后走进来的玩家，听到的就是第 20 秒起的音效；走出半径（+16 格缓冲）停止，再进来重新接上；
- C4 被拆/爆炸/清除 → 立刻给同维度所有人发停止包；
- 听觉半径：`countdown_radius`，默认 **96 格**（16–512）。

### 3.3 音效总表

| 时机 | 事件 | 音量 / 音调 |
|------|------|--------------|
| 安装成功（语音） | `qis4c4:c4plant` | 1.0 / 1.0 |
| 倒计时音轨（分段接力） | `qis4c4:cd_00` … `qis4c4:cd_38` | 3.0 × 距离系数 / 1.0 |
| 滴答 | `minecraft:block.note_block.hat` | 1.5 / 1.0 |
| 拆除成功 | `qis4c4:ctw` | 1.5 / 1.0 |
| 爆炸 | `qis4c4:tw` | 10.0 / 0.8 |
| 安装时的“放好”声 | `minecraft:block.note_block.hat`（放包位置） | 0.8 / 0.9 |

> 远处音量按距离线性衰减，但**下限 0.65**，永不衰减到 0。

## 4. 拆除

### 4.1 开始拆除

触发方式（三者等价，服务端判定）：

- 准星对准 C4 右键（`EntityInteract` / `EntityInteractSpecific`）；
- 手持剪刀或空手，准星 3.75 格内指到 C4 时右键（射线兜底）。

**距离**：开始拆除必须在 **3 格内**（超过 3.75 格提示“距离太远，靠近到 3 格内再拆”）。

判定顺序（任一失败 → 该玩家收到提示、不开始）：

1. C4 未结束/未移除；
2. **队伍**：`allowed_defuse_teams`（警）非空 → 只有名单内队伍；为空 → 所有人都能拆，
   **但已经是安装队（匪）的人除外**（1.7.3 起）；
3. 手持物必须是**剪刀**或**空手**：`§c需要使用剪刀（5秒）或空手（10秒）拆除C4！`；
4. 若已有人在拆：自己则直接返回 true，别人则 `§c<名字> 正在拆除C4！`。

开始成功后：

- 拆除总时长：剪刀 **100 tick（5 秒）**，空手 **200 tick（10 秒）**；
- 记录拆除起点（anchor）；
- 同维度公告 `§e<名字> §f正在用<剪刀/空手>拆除 C4`（6 秒）；
- 所有人的 HUD 出现拆除面板（见 §6），之后每 **4 tick** 刷新一次进度。

### 4.2 中断条件（每个 tick 检查）

| 条件 | 提示文案 |
|------|----------|
| 拆除者下线/死亡/旁观 | `拆除者离开` |
| 主手不再是剪刀或空手 | `工具已切换` |
| 与 C4 距离 > **3.75 格**（3.0 + 0.75 余量） | `距离过远` |
| 相对起点水平位移 > **1.0 格**，或竖直位移 > **1.5 格** | `移动距离过大` |

中断时公告：`§c<名字> 拆除中断！§7(<原因>)`（2.5 秒）。

> 也就是说：**被队友/怪物推动 1 格以内不会中断**（这是 1.7.0 按要求改的），超过才断。

### 4.3 拆除成功

- 记分板 `c4_condition` → **3**，坐标清零；
- 音效 `qis4c4:ctw`（1.5）；
- 公告 `§aC4 已被 <名字> 拆除！`（5 秒）；
- 实体移除，存档坐标与墓碑记录一并清除。

## 5. 爆炸

- 触发：引信到 0；
- 记分板 `c4_condition` → **2**，坐标清零；
- 音效 `qis4c4:tw`（10.0 / 0.8）；
- 公告 `§cC4 已爆炸！`（5 秒）；
- 调用 `level.explode(null, x, y, z, 4.0F, ExplosionInteraction.NONE)`
  —— **实测：不破坏方块、不对实体造成伤害**（与原始模组完全相同的调用，爆炸只承担演出/提示/记分板职责）；
- 实体移除。

## 7. 掉落与拾取

### 7.1 队伍不符自动掉包

- 玩家背包里有 C4，但**不属于安装队** → 每个 PlayerTick 检查一次，把背包里所有 C4 合成一堆丢在脚下；
- 掉落物：拾取延迟 3 秒、永不消失、NBT `c4_drop = 1`；
- 该过程**不**发提示。

### 7.2 死亡掉包

- 条件：`enable_c4_drop = true` **且** 游戏规则 `keepInventory = true` **且** 死亡者身上有 C4；
- 掉落物拾取延迟 2 秒、永不消失、带 `c4_drop`；
- 全服聊天：`§c[C4] §e<名字> §a被击杀，C4已掉落！坐标: §6X:… Y:… Z:…`。

### 7.3 拾取

- 捡起带 `c4_drop` 的 C4 且自己属于安装队 → 本人 `§a 你已捡起C4！`，全服 `§e<名字> §a捡起了C4！`。

### 7.4 掉落标记（1.7.2+）

- 纯客户端：检测“物品实体 + 物品是 C4”，不需要任何数据包；
- 悬浮小牌 + 光柱 + 距离标签（≤24 格显示 `C4 Nm`），被遮挡时变暗（62% 不透明度）但不消失；
- 出屏时屏幕边缘红色菱形 + 距离；拾起即消失，再掉再出现；
- 配置：`dropped_c4_marker`（开关）、`dropped_c4_marker_range`（16–512，默认 64）。

## 8. 队伍身份（CS2 分工）

| 配置 | 语义 |
|------|------|
| `allowed_install_teams`（匪） | 空 = 所有人可装；非空 = 只有名单内可装；含 `""` = 允许无队伍玩家 |
| `allowed_defuse_teams`（警） | 空 = 所有人可拆（**但安装队成员除外**）；非空 = 只有名单内可拆；含 `""` = 允许无队伍玩家 |

读取细节（1.7.4）：

- 队伍名 **trim 首尾空格**、去重、忽略非字符串；例如 `[" terrorists "]` 等价 `["terrorists"]`；
- 匹配是**精确比较**（`player.getTeam().getName()`），大小写必须一致；
- 开服时逐条检查配置队伍是否存在于记分板，缺失/仅大小写不同会 WARN 并列出当前队伍。

## 9. 命令

| 命令 | 权限 | 行为 |
|------|------|------|
| `/c4clear` | 2（OP） | 清除**所有维度**的 C4：已加载的直接 `forceRemove`；只在存档里（未加载区块）的写入“死亡名单”，下次被加载时立刻自删，**不加载任何区块**。返回 `已清除 N 个C4！` 或 `已清除 N 个C4！§7（它们藏在未加载的区块里…）` |
| `/c4roles` | 0 | 只读诊断：两份名单（逐条 ✔/✘是否存在）、你的队伍、你的安装/拆除权限 |

## 10. 记分板联动（给地图/数据包用）

| Objective | 类型 | 含义 |
|-----------|------|------|
| `c4_condition` | dummy，显示名“C4状态” | `0` 空闲 / `1` 已安装 / `2` 已爆炸 / `3` 已拆除 |
| `p1score` / `p2score` / `p3score` | dummy | C4 所在 X / Y / Z（记分板假玩家 `#C4`） |

## 12. 存档结构（`qis4c4_c4`，按维度保存）

- `Positions`：当前存在的 C4 坐标集合（供 `/c4clear` 找“未加载区块里的 C4”）；
- `Tombstones`：清理死亡名单（最多 64 条，超出按最早淘汰），C4 被加载时查表命中即自删。

## 13. 与原始模组（qisumei 1.1.0）的差异清单

**玩法数值：全部一致** —— 安装 70 tick、引信 800 tick、剪刀 100 tick / 空手 200 tick、
爆炸 `4.0F / NONE`、允许方块默认 `end_stone_bricks`、记分板四个 objective 与状态值、
阶段提示（20 秒 / 4 秒，另加了 10 秒一条）、音效事件与音量音调。

**行为/实现上改动的部分（都是修复类）**：

| 类别 | 原版 | 现在 |
|------|------|------|
| 音效投递 | `level.playSound`（半径约 48 格）+ 卸载时 `stopsound @a` | 逐玩家广播同一份原版音效；删除 `stopsound` |
| 引信停摆 | 区块卸载后实体不 tick | FORCED 票据 + `C4Manager` 兜底 |
| 拆除中断判定 | 方块坐标一变就断（被撞一下就失败） | 距离/位移容差（水平 ≤1.0，竖直 ≤1.5，半径 ≤3.75） |
| 倒计时音轨投递 | 一次性整段播放（听不到 / 只能从头听） | 按静音点切 39 段，按当前进度逐段接力（听觉半径 96 格） |
| `/kill`、`/c4clear` | `/kill` 无效；`/c4clear` 只清已加载实体 | 都能清干净，未加载区块用墓碑，不加载区块 |
| HUD | 独立的 `UIMessagePacket` 简单文本 | 复用模组原有独立 UI，新增全员提示/拆除面板，位置在准心下方 |
| 队伍判定的默认全允许 | 拆除队留空 → 匪也能拆 | 拆除队留空时安装队仍不能拆 |
| 队伍名读取 | 原样字符串精确比较 | trim/去重 + 开服校验 + `/c4roles` |
| 掉落 C4 可见性 | 只有 32×32 小贴图 | 悬浮小牌 + 光柱 + 距离 + 出屏指引 |
| 安装队缓存 | 静态 500 ms 缓存（会串玩家） | 去掉缓存，逐玩家实时判定 |

**没有改的**：物品本体、安装/拆除的前置条件本身、引信与拆除时长、爆炸参数、
掉落条件、记分板接口、配置键名与默认值。

## 14. 兼容性

- 客户端与服务端都需安装（HUD 与自定义音效在客户端）；
- 只依赖 Forge 47.x / MC 1.20.1，无第三方依赖；
- `protocol_version = 2`（1.7.x 的 HUD 包格式），客户端与服务端版本需一致。
